# Recursos dos exercícios

As imagens conservam os bytes dos ficheiros de origem, identificados no
manifesto da importação. Recursos de terceiros mantêm as condições das fontes.

| Ficheiro | Origem |
| --- | --- |
| `visao_computacional/dog.jpg` | [PyTorch Hub](https://github.com/pytorch/hub/blob/master/images/dog.jpg) |
| `visao_computacional/bus.jpg` | [Ultralytics](https://github.com/ultralytics/ultralytics/blob/main/ultralytics/assets/bus.jpg) |
| `visao_computacional/zidane.jpg` | [Ultralytics](https://github.com/ultralytics/ultralytics/blob/main/ultralytics/assets/zidane.jpg) |
| `visao_computacional/boats.jpg` | [Ultralytics, exemplo aéreo](https://ultralytics.com/images/boats.jpg) |
| `modulo2/banco_dois_sentidos.png` | Ilustração recuperada da apresentação da formação GSS. |
| `modulo2/peca_fissura_foto.png` | Imagem sintética gerada com ImageGen para a formação GSS. |

Os esquemas em `../modulo2/imagens/` são materiais didáticos da formação:
uma peça com fissura e um gráfico sintético de paragens. As imagens sintéticas
não documentam uma ocorrência real. As respostas gravadas são saídas dos modelos,
identificadas na interface; não são referências corretas por definição.

As fotografias YOLO foram recolhidas no projeto de origem em 13/10/2026.
A autoria das fotografias não é atribuída à formação. O software Ultralytics
e os seus modelos oficiais seguem o [licenciamento do projeto](https://www.ultralytics.com/license).
