# Dia 1 — Formação prática: produção de relatórios com Microsoft Copilot

## Objetivo
Aprender a orientar o **Microsoft Copilot no navegador** para pesquisar, analisar documentos, integrar informações e auditar relatórios produzidos por IA.

A IA deve executar a pesquisa, a análise e a redação. O papel dos participantes é **definir requisitos, formular instruções próprias, fornecer fontes e contexto, avaliar as respostas e refinar o resultado**.

## Ambiente
- Microsoft Copilot no navegador: https://copilot.microsoft.com/ (ou versão web disponibilizada pela organização).
- Não é necessário VS Code, GitHub Copilot nem edição de código.
- Utilizar os recursos de pesquisa, anexação e exportação que estiverem disponíveis na conta. Caso a exportação para Markdown não esteja disponível, copiar o texto e salvar manualmente como `.md`.
- A seleção de modelos, funcionalidades avançadas e leitura de anexos depende da conta e da configuração. Não presumir que um modelo nomeado especificamente esteja disponível.
- Não é necessário instalar skillsets. Caso existam recursos adicionais autorizados, sua utilização é opcional.
