# Environment capabilities

Discover only what the task needs. A documented integration is not an installed
or authenticated integration. Recheck on another OS, machine or host.

| Capability | Purpose | Availability | Evidence / version / OS |
| --- | --- | --- | --- |
| Git | Local version control | Not checked | Not recorded |
| Assistant | Coding and review | Not checked | Not recorded |
| GitLab CLI (`glab`) | Optional issues/MRs/pipelines | Not checked | Not recorded |
| Project runtime | Run/build/test | Not selected | Not recorded |

For additional CLI tools, skills or MCP services, record required versus optional,
inputs/outputs, side effects, configuration variable names and the operation
actually verified. Keep secret values in a credential manager or CI variables.
Do not install dependencies or create accounts just to fill this table.
