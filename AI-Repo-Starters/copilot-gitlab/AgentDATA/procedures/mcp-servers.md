# External integrations and credential requirements

Paths below refer to AgentDATA unless stated otherwise.

Consult mcp/mcp_servers_index.md and the relevant registration before relying on
an integration. Discover actual availability, authentication and access scope.
Use the minimum permissions required. Record variable names and secret-store
locations, never credential values. No server is installed by a catalog entry.
If unavailable, use a suitable available alternative or identify the blocking
dependency while completing independent authorized work.
