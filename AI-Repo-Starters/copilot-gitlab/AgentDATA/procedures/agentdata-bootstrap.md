# Preparing or updating the AgentDATA structure

Paths below refer to AgentDATA unless stated otherwise.

Read AgentDATA/README.md, existing context and the active user request. Preserve
the reference directory names, including capital K in Knowledge, for portable
links. Use the bootstrap-project skill for project discovery and context updates.
Populate context/project.md, decisions.md and handoff.md from evidence and user
answers. Keep templates generic for future copies. Never import requirements,
credentials, environment paths or runtime assumptions from another project.
