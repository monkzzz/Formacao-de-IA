# Publishing a Python distribution only when requested

Paths below refer to AgentDATA unless stated otherwise.

This is optional guidance, not a requirement to adopt Python or publish packages.
For an authorized release, inspect package metadata, target index, version,
license and existing release process. Build and inspect distributions; test
installation in an isolated environment before publication. Use the project's
credential mechanism. Verify the requested index artifact after publication.
Do not upload or configure credentials merely because this procedure exists.
