# Copyable AI repository starters

Choose one independent folder and copy its contents into a repository root,
including hidden directories. No installation script or symlink is required.

- [Codex + Claude Code + GitLab](codex-claude-gitlab/START-HERE.md): both assistants
  share working rules, context and a handoff; each has its native entry point.
- [GitHub Copilot + GitLab](copilot-gitlab/START-HERE.md): VS Code agent workflow
  with Copilot instructions and a native bootstrap skill.

Both include Linux/Bash and Windows/PowerShell instructions, the complete original AgentDATA folder tree and project
templates, and GitLab issue/MR templates. Follow START-HERE.md for new or existing
repositories. Do not copy this containing folder into every project; copy the
contents of the chosen variant. Keep the original unpopulated for future reuse.

These files configure agent behavior and preserve context. They do not install
assistants, grant GitLab access, select a software stack or enable CI/deployment.

Both variants preserve all original AgentDATA reference filenames, including
Knowledge/ capitalization, catalogs, procedures and safe secret examples. Their
contents are adapted; no course-specific project context or live credentials
are copied. Native assistant entry points and skills remain outside AgentDATA.
