# Publishing an npm package only when requested

Paths below refer to AgentDATA unless stated otherwise.

This is optional guidance, not a requirement to adopt Node or publish packages.
For an authorized release, inspect package identity, registry, version, included
files, license and existing release process. Build/test the actual package and
review the archive contents before publication. Preserve credentials outside Git.
Publish only to the requested registry and scope; verify the resulting artifact.
Do not add a Node runtime or invoke publication merely because this file exists.
