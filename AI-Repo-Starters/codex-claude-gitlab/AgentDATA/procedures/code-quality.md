# Code structure, contracts and error handling

Paths below refer to AgentDATA unless stated otherwise.

Follow the project's language and established conventions. Keep dependencies and
responsibilities clear; validate external boundaries and report useful errors.
Avoid unrelated formatting, speculative abstractions and incidental upgrades.
Document non-obvious behavior, public contracts and compatibility constraints.
Choose meaningful tests for new logic; do not enforce arbitrary function lengths
or impose a naming convention from a different programming language.
