# Local Git operations and synchronization

Paths below refer to AgentDATA unless stated otherwise.

Discover the current branch, worktree and changes first. Stage explicit paths,
review the staged diff and use the existing author identity and project message
convention. Preserve unrelated work. Do not reset, clean, stash, force-push or
rewrite history as a workaround without authorization. Read gitlab.md for remote
issues, merge requests, pipelines and protected branch behavior.
