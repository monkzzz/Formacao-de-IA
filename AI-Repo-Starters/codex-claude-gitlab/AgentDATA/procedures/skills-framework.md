# Discovering and maintaining skills

Paths below refer to AgentDATA unless stated otherwise.

Use skills/skills_index.md to distinguish expected, discovered and verified
skills. Store executable/discoverable skills in the assistant's native directory;
AgentDATA/skills/ is a catalog, not a universal discovery location. The skill
record must identify its actual path, trigger, dependencies and verified scope.
Load only relevant instructions. Copying a skill does not prove automatic discovery.
