# Maintaining project and agent documentation

Paths below refer to AgentDATA unless stated otherwise.

Keep current requirements and commands in context/project.md, approved choices
in context/decisions.md, operational guidance in procedures/ and auxiliary reports
in docs/. Use references/ for external sources with attribution and version/date.
Update only the documentation affected by the task. Check relative links and
command consistency. Never describe an unexecuted command as verified.
