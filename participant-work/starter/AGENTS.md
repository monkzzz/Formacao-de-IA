# Agent working agreement

These rules govern this starter and projects created from it. Follow explicit user
instructions and applicable parent instructions first. Load project details on demand.

- Communicate and write new participant work in English; preserve quoted source text.
- Read this file, `README.md`, `context/project.md`, `context/handoff.md`, relevant
  decisions and knowledge, and applicable nested instructions before editing.
- Inspect Git status and affected files. Preserve unrelated edits, untracked files,
  datasets and historical evidence. Use explicit file paths when staging.
- State the intended outcome, affected files and relevant verification briefly.
  Resolve routine choices independently and complete the authorized scope.
- Ask for missing information only when it materially blocks a requirement or an
  irreversible action lacks authorization. Existing authorization carries forward.
- Follow [the workflow](procedures/workflow.md) for planning, execution and review;
  follow [Git and safety](procedures/git-and-safety.md) for versioning and external actions.
- Run appropriate checks and inspect affected interfaces. Record exact results and
  limits in [evidence](evidence/README.md). Never call an unrun check successful.
- Keep verified facts, assumptions, decisions and open questions distinct.
  Put reusable findings in [knowledge](knowledge/README.md); update the handoff.
- Discover tools before relying on them. Consult [capabilities](capabilities/README.md)
  for CLI, skill and MCP contracts. A catalog entry is not proof of availability.
- Never commit secrets, environment folders, downloaded caches or model weights.
- Match project conventions. Avoid unrelated refactoring, arbitrary language defaults
  and unnecessary tests for low-impact documentation edits.
- Report the outcome, verification and remaining limits. Commit when requested or
  authorized by the active project agreement; publication needs its own authorization.

This agreement does not require a particular assistant, language runtime, remote
service, model, dataset or deployment platform. A fresh session must discover those
from project context rather than importing assumptions from the previous project.
