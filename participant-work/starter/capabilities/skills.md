# Skill registry

Current project skill: [bootstrap-project](../.github/skills/bootstrap-project/SKILL.md),
source version 1.0.0, participant-authored under the course's CC BY 4.0 terms.
It establishes or updates project context through an interview and an approved
proposal; ordinary implementation requests do not activate it. Inputs: active
request, existing context and participant answers. Outputs: approved context,
decisions and handoff. Dependencies: a Markdown skill-capable host and repository
read/write tools; no installer, libraries or external account. Side effects: only
approved context writes, no automatic implementation or publication.

Availability: source present; format checks are recorded in the containing course
submission. Copilot discovery, interview behavior, approval handling and recovery
are **not yet verified**. Explicit loading by another assistant must be recorded
separately from native host discovery. No personal machine paths or globally
installed skill inventory are assumed in a future project.

Use general instructions for always-applicable behavior. Use a specialized skill
when a repeatable task benefits from focused procedures, supporting resources or
tool contracts. Do not create skills merely to duplicate the working agreement.

For each candidate record name, purpose, trigger and exclusions, source/license,
version/location, host compatibility, inputs/outputs, dependencies, side effects,
access needs and the shared [availability evidence](README.md).

Discover skills through the active host's supported catalog and inspect the actual
instructions before use. Follow the user's choice of assistant. A skill file on
disk proves presence only; record actual invocation and observed behavior separately.
Do not silently install a substitute for a participant-authored exercise deliverable.
