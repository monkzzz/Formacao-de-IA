# Procedimento: documentacao

## Quando carregar

Carregar quando uma mudanca alterar comportamento, contrato, configuracao, comando, pipeline, arquitetura, fluxo operacional ou expectativa de uso.

## Regras

- Documentacao deve refletir comportamento real.
- Nao manter documento mentindo.
- Nao criar documentacao inflada.
- Focar no que importa para operar, manter e entender o sistema.

## Locais

- `README.md`: orientacao principal do repositorio.
- `AGENTS.md`: regras sempre ativas e indice de procedimentos.
- `AgentDATA/docs/`: documentos auxiliares nomeados como `{timestamp}_{descricao}.md`.
- `AgentDATA/Knowledge/`: achados tecnicos reutilizaveis.
- `AgentDATA/procedures/`: procedimentos operacionais carregaveis sob demanda.
