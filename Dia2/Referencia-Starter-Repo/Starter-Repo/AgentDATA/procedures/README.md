# procedures

Procedimentos dinamicos carregados sob demanda pelo agente.

Cada procedimento deve explicar:

- quando carregar;
- objetivo;
- sequencia operacional;
- validacao esperada;
- registros ou commits relacionados.

Procedimentos de tools:

- `cli-tool-build.md`: construir, alterar e validar CLI tools.
- `cli-tool-documentation.md`: documentar CLI tools, comandos, exemplos e help.
