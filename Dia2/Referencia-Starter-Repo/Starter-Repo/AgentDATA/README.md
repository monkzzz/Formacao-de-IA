# AgentDATA

Area de contexto vivo do agente.

Use esta pasta para guardar informacoes auxiliares de execucao, memorias, documentos, logs, scripts, referencias, segredos locais, conhecimento estruturado e procedimentos dinamicos.

## Subpastas

- `context/`: contexto de sessao e configuracao operacional.
- `memories/`: memorias e aprendizados com timestamp ISO 8601.
- `docs/`: documentos auxiliares em Markdown.
- `logs/`: logs estruturados, preferencialmente JSON.
- `scripts/`: scripts auxiliares em TypeScript.
- `references/`: exemplos, trechos e referencias tecnicas.
- `secrets/`: configuracoes privadas e credenciais locais.
- `Knowledge/`: registros tecnicos reutilizaveis.
- `procedures/`: procedimentos carregaveis sob demanda.
- `skills/`: catalogo de skills esperadas, instaladas ou recomendadas.
- `mcp/`: catalogo de MCP servers, contratos e requisitos de credenciais.
- `tools/`: catalogo de CLI tools, automacoes e comandos operacionais.

Segredos reais nao devem ser commitados.
