# skills

Catalogo de skills relevantes para projetos derivados desta seed.

Leia esta pasta quando uma tarefa depender de capacidade especializada.

Arquivos principais:

- `skills_index.md`: lista curta das skills do projeto.
- `skill_registry_template.md`: modelo para registrar uma nova skill.

Use registros de skill para declarar:

- skills esperadas para o projeto;
- quando cada skill deve ser usada;
- fonte de instalacao ou documentacao;
- status local: desejada, instalada, ausente ou desativada;
- observacoes de compatibilidade.

Nao copie conteudo longo de skills para ca. Referencie a origem e registre apenas o contrato de uso no projeto.
