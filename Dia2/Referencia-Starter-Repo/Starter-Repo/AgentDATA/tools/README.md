# tools

Catalogo de CLI tools relevantes para este projeto.

Leia esta pasta quando uma tarefa envolver comando de terminal, automacao local, script operacional, binario distribuivel ou ferramenta interna.

Arquivos principais:

- `tools_index.md`: lista curta das CLI tools do projeto.
- `tool_registry_template.md`: modelo para registrar uma nova CLI tool.

Use registros de tool para declarar:

- comando e subcomandos;
- objetivo e publico-alvo;
- entradas, saidas e efeitos colaterais;
- dependencias e ambiente esperado;
- exemplos de uso;
- validacao e smoke tests;
- riscos operacionais.

Nao registre segredos em exemplos. Use placeholders claros.
