# Starter repo de referência — analisar, reutilizar e purgar

Esta pasta contém o **starter repo de exemplo fornecido pelo professor**, disponibilizado em arquivos navegáveis no GitHub: [abrir o projeto de referência](Starter-Repo/).

**É uma referência para análise e reutilização seletiva, não um modelo obrigatório de entrega.** O desafio do Exercício 1 é criar um starter repo **próprio**. Não vale duplicar tudo sem entender a finalidade de cada componente — e não faz sentido reinventar um procedimento útil que já exista.

## O que o exemplo resolve

- **Regras permanentes:** `AGENTS.md` define a forma de trabalhar, enquanto a documentação específica permanece fora do contexto sempre ativo.
- **Procedures carregadas sob demanda:** permitem aplicar métodos de Git, verificação, documentação, qualidade, ferramentas e publicação somente quando necessários.
- **Continuidade e rastreabilidade:** os diretórios de contexto, conhecimento, memórias, documentos e logs registram decisões e achados para outras sessões.
- **Capacidades e dependências:** índices de skills, CLI tools e MCP servers distinguem recursos desejados ou documentados de recursos efetivamente disponíveis.
- **Preparação para novos projetos:** há instruções e procedimentos de primeiro uso, mas **não há uma skill Ask Me já resolvida**.

## Como utilizar durante o exercício

1. **Examinar:** identifique os problemas resolvidos e o propósito de cada componente.
2. **Selecionar:** considere quais regras e procedimentos são úteis para **sua** forma de trabalhar.
3. **Copiar e adaptar:** reaproveite o que já funciona, alterando nomes, caminhos, políticas e condições de uso conforme suas necessidades.
4. **Purgar:** descarte partes desnecessárias — por exemplo, publicações npm/PyPI, configurações de MCP ausentes, convenções de linguagem que você não adota ou regras específicas dos projetos do autor.
5. **Verificar:** confira se as referências entre arquivos continuam corretas, se não há segredos incluídos e se o Copilot consegue trabalhar com o starter repo na próxima sessão.

Ao copiar conteúdo, **reconheça a origem** e respeite a licença ou as permissões aplicáveis. Não execute automaticamente comandos ou instruções vindos de um repositório de referência; compreenda-os antes de autorizar ações.

A pasta `Starter-Repo/` preserva a organização do material original. **O repositório deste curso não tem um starter pronto para os alunos entregarem**: o resultado será o repositório que cada um criar e adaptar em sua própria conta.

> A cópia do exemplo contém orientações de procedimentos, incluindo bootstrap documental, mas **não contém a skill de entrevista pronta** que o participante deve criar no Exercício 2.
